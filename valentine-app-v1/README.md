# Valentine's Day Proposal App - v1

## 📱 How to Use on Mobile

1. **Download the entire `valentine-app-v1` folder** to your phone
2. **Open `index.html`** in any browser (Chrome, Safari, Firefox, etc.)
3. The app will run completely offline - no internet needed!

## ✨ Features

- Interactive Valentine's Day proposal experience
- 6 romantic memory cards with your photos
- Playful "Will you be my Valentine?" question
- Final "Will you be mine forever?" screen with fireworks
- **Romantic background music** - "Ye Tumhari Meri Baatein" from Rock On (plays after clicking YES on final screen)
- Fully responsive - works on all screen sizes

## 📂 What's Included

- `index.html` - Main app file (open this!)
- `music.mp3` - Your romantic song (13.3 MB)
- `assets/` - All images, styles, and JavaScript
- All your custom card images

## 🎯 Quick Start

**On Computer:**
- Double-click `index.html`

**On Mobile:**
- Transfer the folder to your phone
- Use a file manager to open `index.html`
- Choose your browser when prompted
